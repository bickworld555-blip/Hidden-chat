🐛 TROUBLESHOOTING
================================================================================

ISSUE: Attachment menu not appearing
SOLUTION:
  - Clear browser cache: Ctrl+Shift+Delete
  - Check browser console for errors (F12)
  - Verify AttachmentMenu.jsx is imported in ChatWindow.jsx
  - Run: npm run build
  - Refresh page (Ctrl+R)

ISSUE: Call logs not showing
SOLUTION:
  - Ensure calls complete properly (don't just disconnect)
  - Check browser console for errors (F12)
  - Verify CallStatusBubble.jsx is imported
  - Check messages contain "call:" prefix
  - Run: npm run build
  - Refresh page

ISSUE: Styling not applied correctly
SOLUTION:
  - Clear browser cache (Ctrl+Shift+Delete)
  - Verify CSS file is loaded (DevTools > Sources)
  - Check for CSS errors in DevTools Console
  - Run: npm run build
  - Refresh page (Ctrl+F5)

ISSUE: Dark theme not working
SOLUTION:
  - Verify .dark-theme class on root element
  - Check theme toggle button adds/removes class
  - Check CSS selectors in styles.css
  - Clear cache and rebuild
  - Test in DevTools Console:
    document.querySelector('body').classList.toggle('dark-theme')

ISSUE: Features not working after deployment
SOLUTION:
  - Verify dist/ folder was uploaded completely
  - Check MIME types on server (.js and .css files)
  - Clear browser cache
  - Test in incognito/private mode
  - Check browser console for errors
  - Verify index.html references correct asset paths
