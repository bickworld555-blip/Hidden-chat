## 🔧 Technical Implementation

### Architecture
```
App.jsx
├── callStartTimeRef (tracks call duration)
├── handleCallEnd() (logs call with metadata)
└── CallOverlay onClose → handleCallEnd

ChatWindow.jsx
├── MessageInput
│   ├── AttachmentMenu (new component)
│   └── handleAttachmentMenuSelect()
└── MessageBubble
    ├── Parse call: prefix
    └── Render CallStatusBubble (new component)

Store.js
└── logCall() method
    └── Creates call: messages
```

### State Management Flow
```
Call Starts
    ↓
callStartTimeRef = Date.now()
    ↓
Call Connected (active)
    ↓
Call Ends/Fails
    ↓
Duration = now - callStartTimeRef
    ↓
logCall(peerId, {duration, mode, status})
    ↓
Message created with call: prefix
    ↓
Added to store
    ↓
Rendered as CallStatusBubble
    ↓
Persisted in chat
```
